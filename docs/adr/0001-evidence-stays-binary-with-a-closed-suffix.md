# 证据标记保持二元，用封闭后缀词表承载「查了没找到」

竞品 `academic-program-application` 把 `Not found` 与 `Unclear` 分成独立状态，这有实务价值——「我没查」要用户去官网查，「查了官网就是不写」要用户发邮件问 admissions，下一步动作完全不同。但地图已锁定证据标记为**二元**（`✓ <链接>` / `待核实`），改成三态会让 `evidence` 列变成三值枚举，并让「已核实」不再有唯一判别式。

决定：**保持二元，给 `待核实` 加一个封闭词表的括号后缀**——`官网未列` / `口径不清` / `需邮件确认`，无后缀即「还没查」。后缀不参与机械汇总（`grep 待核实` 照旧全中），只在生成待核实自查清单时变成行动提示。

这复用了换季降级已经在用的括号约定，但**后缀因此有两种，且会同时出现**：原因后缀取自封闭词表，降级后缀（`<上一季> 核过：<链接>`）是唯一形态、参数化、携带数据而非分类。共存写法为 `待核实（官网未列；2026fall 核过：<链接>）`——上季标 `✓` 的行降级后被重查、发现官网已不再列出，就会走到这里，不是边角情形。

## Consequences

原因后缀是自由文本形态但语义上是枚举——**词表必须封闭**，否则会漂移成散文，而散文无法机械转成行动提示。新增原因后缀词等于改词汇表，不是随手写。

代价：解析 `待核实(...)` 要处理两种后缀与它们的共存，比三值枚举复杂。这是为守住「`✓` 有唯一判别式」付的价。
