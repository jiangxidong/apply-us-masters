# 一条检查有四个位置，必须按序占据：规则原文 → 登记 → 实现体 → CI

- 状态：已接受
- 日期：2026-08-15
- 来源：[#63 纯 awk/grep 可判的新检查该落在哪 + 哪几条进 CI](https://github.com/jiangxidong/EduApplication/issues/63)

## 背景

六次独立到达同一个缺口：#36 交回一条、#48 交回三条、#62 一条、#52 一条，全部是「纯 `awk`/`grep` 可判、有明确被测对象、但没有家」。地图 fog「知识时效性运维」那一片写着「这一片下次醒来先答它」。

把六条摆在一起看，问题不是「它们该放哪个文件」，而是**「放哪」这个问题本身被问成了一维的**。票面给的三个选项——`docs/checks.md` 的表 / `derive-demo.sh` / 先建 `evals/`——**不是三选一，是同一条检查生命周期上的三个不同位置**。

本仓库已经在这三个位置上各摔过一次：

| 跳过的位置 | 后果 | 实例 |
|---|---|---|
| **规则原文** | 脚本里的字面量成了契约的**编译时抄录**，契约改了没有任何机制会报错 | [#57](https://github.com/jiangxidong/EduApplication/issues/57) 把 `derive-demo.sh` 的 A3/A4 判为恒真：「脚本从不读 `CONTRACT.md`，连在副本内活读一次都做不到」 |
| **登记** | 实现体存在但清单收不到，同一条规则长出第二个实现 | [#57](https://github.com/jiangxidong/EduApplication/issues/57) 脚注 7：`section-prefix-match`（登记了、零实现）与 `trace-packet.sh` `[2b]`（有实现、实现的是过时版本）是同一条规则的两个东西 |
| **实现体** | 给一个不存在的程序排 CI | #57 的原话：「对不存在的程序问『参照物在副本内还是副本外』是**范畴错误**」 |

## 决定

**四个位置，按序占据。一条检查在任一时刻只占据其中一个前缀。**

> **① 规则原文** —— 唯一权威在裁决它的那份 ADR 或契约条款（[ADR 0016](0016-the-checklist-holds-names-and-pointers.md) ①）。**没有权威就不许登记**：登记一条没有规则原文的检查，等于往清单里放一个指向空处的指针。
>
> **② 登记** —— 进 [`docs/checks.md`](../checks.md)，持名与指针。准入是 ADR 0016 ② 的被测对象三取值（`契约` / `repo 文档` / `工作区`）。🔴 **判据是「它能宣布谁违规」**；宣布不了任何人违规的东西**根本不是检查**，它没有位置 ① 之后的任何位置——它是派生视图或体检。
>
> **③ 实现体** —— 只有一处，在 `evals/`。演示脚本（`derive-demo.sh`）不是回归套件。过渡期里实现体在别处时，**如实记在「尚未实现」节**，`evals/` 建起来时**同一刀迁移并删除原处**——ADR 0016 已否掉「允许两份并存」。
>
> **④ CI** —— 四条合取，全满足才够格：
>   1. **有实现体，且它住在 `evals/`**；
>   2. 配了至少一条 `evals/fixtures/violations/` 夹具，且**实测能让它翻红**（[ADR 0017](0017-a-check-that-compares-against-a-forkable-copy-is-vacuous.md) 推论 2：全绿不是证据）；
>   3. **不须联网、不须跑 agent**（[#14](https://github.com/jiangxidong/EduApplication/issues/14) 已判）；
>   4. **说得出参照物在副本之外的什么地方**（ADR 0017 推论 1）。
>
> 🔴 **第 4 项对 `被测对象 = 工作区` 的检查，由第 2 项的夹具满足，不是一道独立的闸。** 这类检查的参照物是 `CONTRACT.md`，而它与被检对象 `sample-workspace/` **同处一个可整体冻结的副本**（实测：两个 prototype 分支上该目录逐字副本相同），正是 [ADR 0017](0017-a-check-that-compares-against-a-forkable-copy-is-vacuous.md) 判的形状；而 ADR 0017 又否掉了跨分支取参照物。若让第 4 项独立站着，**十八条里没有一条可能通过**，本条给的「终止条件」当场变成一句空话。真正的副本之外的参照物是 `evals/fixtures/violations/` 里那份**故意写坏的夹具**——它不随被检副本一起冻结，所以「实测能让它翻红」这一条同时兑现了第 2 项与第 4 项。

**「哪几条进 CI」因此不是名单问题。** 今天的名单是空的，因为十八条**没有一条**满足第 1 项（`evals/` 在全部 16 个 ref 上零命中）。#9 定的「**暂**不进 CI」已经被续期过三次（#9 → #14 → ADR 0016 → `docs/checks.md` 触发节），每一次都指向下一处，**没有一次写下什么时候不再是「暂」**。本条给的是终止条件：第一条满足四项的检查落地那天，它自己就进 CI，不必再开一张票问「可不可以」。

## 被否掉的

**「先建 `evals/`，五条跟着建」。** `evals/` 是 [ADR 0019](0019-an-absence-needs-a-consumer-branch-not-a-registry.md) 的**丙类真欠货**（该 ADR 的防蔓延闸就是拿它举的例），而丙类**只能进它自己的票**，挂在别人票的「顺带」里等价于不登记。把五条的登记压在建 `evals/` 后面，就是让登记的寿命等于那张票剩下的开票时间。**登记与实现解耦，正是 ADR 0016 花钱买来的东西**——本条不把它退回去。

**「落 `derive-demo.sh`」。** 它第 2 行自陈是演示（「证明派生视图可以机械算出，不必落盘」）；且它在两个 prototype 分支上各有一份**逐字副本**（实测 `shasum` 相同），闸门落进去等于回归套件同时住在两个未合并分支上，任一分支单独往前走就分叉——#57 的 A2 已经演示过这个地雷（id 归一了、pattern 没跟着搬，闸口**静默消失**）。

**「继续暂不进 CI，不给判据」。** 一个没有终止条件的「暂」是永久，而它的成本是持续的：ADR 0016 自己写着「若 `evals/` 始终不建，这份清单就退化成第三份从未被执行过的散文」。

**「给每条检查加参照物字段」。** 归 [#66](https://github.com/jiangxidong/EduApplication/issues/66)，ADR 0017 的作废条件明写要等有样本之后再判。本条只把位置 ④ 的判据 4 定成**建的时候的要求**，不定成表的一列。

## Consequences

**`docs/checks.md` 从十三条涨到十八条，全部零 CI。** 这是明知接受的：登记便宜、实现贵，本条把两者的价格差写明，而不是靠「不登记」假装欠账不存在。**它不是第二份欠账清单**——ADR 0019 禁的是造第二份，进同一份是对的。

**「一行代码都还没有」这句话作废。** 十八条里有两条今天由 `derive-demo.sh` 跑。`docs/checks.md`「尚未实现」节已改成如实记账。

**两条候选被判到检查之外，且不开票。** 缺口三分类（#48 自己就把它列为派生视图；`CONTEXT.md`「缺口」词条持有它的六类落盘表，明写「现算现打、绝不落盘」）与 `✓` 链接体检（#14 已判 404 不算回归失败——URL 挂了的时候违规的不是工作区）。两者都宣布不了谁违规，按 ADR 0019 是**甲类合法缺席，一张票都不开**。

**位置 ② 的准入判据是可被滥用的那一头。** 「它能宣布谁违规」需要人判，判错的方向是**把闸门读成视图**（少一道闸，静默）而不是反过来。顶着它的只有 ADR 0016 ② 的三取值封闭表——第四个取值出现的那天，本条要重算。

**它不保证第一条检查真的被写出来。** 与 ADR 0016 同一个软肋，顶着它的只有 `evals/` 那张独立票。

## 作废条件

- 若 `evals/` 建起来且第一条满足四项的检查落地，「今天名单为空」当场作废，**四条判据仍成立**；
- 若 [#66](https://github.com/jiangxidong/EduApplication/issues/66) 判定给每条检查加上参照物标注并能机械校验，判据 4 从人肉纪律降级为工具约束，本文正文应改写为对那层标注的要求（同 ADR 0017 的作废条件 ②）。
