# 分档以「硬门槛」为锚，按被拒风险落在哪定义

分档（冲刺 / 匹配 / 较稳）最自然的定义方式是概率带（「录取率 30% 以上算匹配」），但 [#5](https://github.com/jiangxidong/EduApplication/issues/5) 已证实五所样本无一公开院校分级名单，且绝大多数美国 coursework master 不公布项目级录取率——按概率定义的档位在这个域里**取不到数**，只会退化成「凭经验」。

决定：**四档全部以「硬门槛」（项目公开写明的最低准入条件）为锚，按「你被拒的主要风险落在哪」定义**，而不是按概率带。`reach` = 风险在竞争且竞争数据不公开；`match` = 有公开信号表明你在录取群体中段；`safer` = 你明显超过公开门槛，风险不在你的条件；`undecided` = 三条都写不出依据。

## Consequences

硬门槛是可核实的事实（可标 `✓`），所以每一档的断言都有一个可取证的起点——这给了 [#16](https://github.com/jiangxidong/EduApplication/issues/16)（「依据」格能填什么）一个可操作的出发点，而概率带定义给不了。

`safer` 在这个定义下**从不断言「会录」**，只断言「拒你的理由不会是你的条件」。这正是地图锁定「用 safer 不用 safe」想守住的东西，现在它有了定义级的支撑，不再只是措辞约定。

## 后续

[`0009`](0009-safer-is-defined-by-the-programs-second-published-line.md) 补上了本 ADR 欠下的定义并收窄了两处措辞：

- **`safer` 的「明显超过」**已由「跨过该项目**公布的第二条线**」取代——标定权在学校，不在本产品。
- **`reach` 的「竞争」**显式化为「**别的申请人比你更强**」。取另一种读法（名额/口味/运气）会让 `reach` 蕴含 `safer` 的断言，两档在逻辑上不分离。
- **四档扩为五档**：新增 `ineligible`（全部公开维度中至少一个已取证未达标）。本 ADR 的四档全部以「满足硬门槛」为前提，「查到门槛、你不满足」在原表里无处安放。

「硬门槛是分档**唯一合法**的锚」这句（本 ADR 时期的措辞，彼时 `0005` 的准入测试尚不存在）在 `CONTEXT.md` 中已改为「最常见的锚」——准入以 `0005` 为准。
