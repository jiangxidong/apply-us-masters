# ADR 0022：词表外冒出来的节名不是加项的理由，先去查范围话

- 状态：已接受
- 日期：2026-08-16
- 来源：[#65 样例里有五个节名过不了 §1.2 的封闭词表，而 section-prefix-match 今天就会红](https://github.com/jiangxidong/EduApplication/issues/65)

## 背景

`CONTRACT.md` §1.2 的十节封闭词表是 `channels/*.md` 唯一合法的切法。当一个 `##` / `####` 标题过不了前缀匹配时，**连着两张票的第一反应都是给词表加项**：

- [#44](https://github.com/jiangxidong/EduApplication/issues/44) 想为 STEM/CIP 开第 11 个节 —— 被 [ADR 0008](0008-the-owner-binds-to-a-section-not-a-file.md) **限定 5** 拦下，代价是那张票整个走了一遍错路。
- #65 的**前一版**想为 `学位形态` 开第 11 个节 —— 没有被拦下，因为它把限定 5 的引用义务当成了一道可以自己填答案的题。

前一版的援引实测垮在三处：

1. **十一项里今天只有两项有写下来的范围话**（§1.2 里「`X` 收……」形式的 🔒 句只有 `费用与资格` 一条，`硬约束` 另有「装的是……／不收」一句；其余九项零）。
2. 它逐项引范围话的那张表**只点了四项**，另外六项（`平台与账号` / `AI 使用政策` / `文书规格` / `材料上传` / `推荐信机制` / `冻结点`）**全文未提** —— 这条它自己在「我没做到的」里承认了。
3. 它点名的那张牌被**引错了**：`费用与资格` 的范围话原文写的是「项目自身的**资格属性**」，被引成「**授予申请人**某项资格」——凭空加了一个原文没有的限定词，方向从「项目」偏到「申请人」。而 [ADR 0018](0018-a-global-lookup-table-stays-out-of-the-workspace.md) 恰把 CIP code 定性为「**这个项目自己的**属性」。

⇒ 三个「收不下」里，一个是转述、六个根本没被检查过。按限定 5 自己的话：**「没有范围话时，『收不下』不是一个判断，是一次转述。」**

## 决定

> **一个 `##` / `####` 标题过不了封闭词表，唯一被授权的第一步是去查这条事实落在哪个已有节的范围话之内，不是给词表加项。**
> 默认假设是「**这条事实已经有家，只是写它的人没查范围话**」，不是「词表缺一项」。

处置顺序因此是：**① 查已有节的范围话 → ② 范围话不存在就先补范围话（限定 5 已要求）→ ③ 补完仍收不下，才谈加项。**

## 与既有条款的分工

**与 ADR 0008 限定 5 不重叠。** 限定 5 管的是「**加项时要引什么**」；本条管的是「**在决定要不要加项之前先做什么**」。限定 5 是事后堵漏，本条是事前定向——#44 靠限定 5 被拦住，但那张票已经整个走了一遍错路，成本就是本条要省掉的那一份。

**与 [ADR 0017](0017-a-check-that-compares-against-a-forkable-copy-is-vacuous.md) 不重叠。** 0017 说的是「参照物与被检对象同处一个可分叉副本 ⇒ 检查恒真」，而限定 5 自陈范围话检查正是这个形状。**本条不试图机械化**：它改的是**默认假设**，而默认假设的成本为零——它只决定第一步去读哪份文件。

## Consequences

**#65 自己是第一个正例。** 按新顺序走：三处 `#### 学位形态` 全部在两句**已经写下来的**范围话里找到了家（`费用与资格` 与 `项目内容`），两个 `英语门槛` 在一条**已经闭合的**链子里找到了家（§1.2 归属表 → ADR 0004 → `CONTEXT.md`「硬门槛」）。**`section-prefix-match` 的 FAIL 从 5 降到 0，而封闭词表一项没加、`CONTRACT.md` 的十节表逐字未动。**

🔴 **反向代价，老实记下**：处置顺序把「加项」推到第三步，**真缺类别的情形会被多绕两步**（[#23](https://github.com/jiangxidong/EduApplication/issues/23) 的 `项目内容` 就是那种情形）。这笔交换是有意的——绕两步的成本是两次读；而误加一项的成本是**封闭词表反向不可逆**：ADR 0008 已记，撤回一项要重扫三个样例 ＋ 两份契约副本 ＋ 两个包。

**不新增机械检查。** 同限定 5，本条管的是**读检查输出的人**，靠人读、靠 review。**写明于此，免得下一个 session 以为它被机械保护着。**

🔴 **排序**：改样例节标题本身就是夹具改动，**必须与本 ADR 同批或在其后落盘** —— 否则这条新规的第一个适用对象就被绕过去了。

## 作废条件

若将来出现一处事实，**十一项的范围话都补齐了、逐条查过仍然收不下**，那就是限定 5 意义上的真加项，本条不阻挡它——本条只要求那一步走在第三位，不要求它永不发生。
