# 主张是全局唯一的一等对象，文书与推荐信共用同一个集合

[#10](https://github.com/jiangxidong/EduApplication/issues/10) 把「主张」定成素材门槛的**单位**（硬约束 = 不许有无素材支撑的主张），
但把判据外显成**产物末尾的「主张 → 支撑素材」对照表**——即主张是**文书局部的、派生的**，没有独立的持久存在。

[#12](https://github.com/jiangxidong/EduApplication/issues/12) 的三条决议全部要求它**先于文书存在**：
推荐信的差异化轴是主张（不是素材）；support pack 门槛按主张判；
推荐人线的输入只有「候选人名单 + 主张清单」，因此可与文书线并行、**且应最早起**（推荐人要两三周）。

让推荐人线自建一套主张 = **第二个真相源**（竞品坑 #9：同一事实索引两遍，检索互相稀释），被
[#4](https://github.com/jiangxidong/EduApplication/issues/4) 的原则直接封死。

决定：**主张是全局一等对象，落盘在工作区根的 `claims.md`；全局只有一个主张集合，
文书与推荐信都从它取。** 模型上：**文书是申请人自述主张，推荐信是第三方佐证同一批主张**——
一份连贯的申请，两者论证的是同一个集合。

考虑过并否掉的两个更便宜的方案，都倒在同一条判别式上：

> **必须能表示「一条有零个支撑素材的主张」。**

- **主张作为素材的一个字段**（每条素材声明它支撑哪条主张）：主张只作为素材的属性存在，
  **零素材的主张在物理上无法表示**——而 #12 的三类缺口里第一类就是「缺素材 = 这条主张没有素材支撑」，
  #10 又承诺每个缺口带属性「属于哪条主张」。产品最需要暴露的缺口恰好不可表达。
- **读取时从素材现推**：同上，且推荐人线在文书动笔前就要跑，那时无从推起。

第二条支撑理由来自 #4 的派生视图判别式（「这行字为了保持为真，需不需要被改写？」）：
主张是**被撰写的判断**，不是从别处推得的镜像。这和 [#11](https://github.com/jiangxidong/EduApplication/issues/11) 的 `tier_basis`、
#12 的「主张 → 推荐人分配」是同一形状——那两处都已判定必须落盘。

## Consequences

**#10 的两处修订。**

1. 产物末尾的「主张 → 支撑素材」对照表从**判据表**降级为**渲染视图**：真相在 `claims.md`，
   对照表是现算的呈现。它仍是 [#14](https://github.com/jiangxidong/EduApplication/issues/14) 的回归检查项。
2. 文书从「**发明**主张」改为「**从主张清单里选**」。全局主张集因此 ⊇ 任何一篇文书用到的主张集。

**素材门槛的作用域随之收窄**：硬约束「不许有无素材支撑的主张」卡的是**进了成稿的主张**，
**不是全局集**——全局集里允许存在零素材的主张，那正是缺口本身。
一条 `materials` 为空的主张进不了任何成稿，但能进带缺口标注的骨架。

**两个消费方 ⇒ 落在根目录，不落 `essays/` 下。** 沿用 #12 把 `essays/materials/` 提到根 `materials/` 的同一条理由：
推荐信线是第二个消费方，`essays/` 前缀会说谎。

**「谁能证实」不进 `claims.md`。** [#13](https://github.com/jiangxidong/EduApplication/issues/13) 已定可验证性是**素材**的独立属性；
主张层再存一遍就是第二真相源，且会让 #12 的 pack 门槛在两处失配。
门槛本来就是纯派生：顺 `materials` 列跳到素材，读素材的可验证性。

**「唯一写入者」再破一次。** 主张必须先于文书存在（推荐人线最早起），却又要在文书阶段被打磨，
因此 `claims.md` 是**两阶段写**：冷启动/画像阶段落初稿，文书阶段打磨。
[#9](https://github.com/jiangxidong/EduApplication/issues/9) 的「owner = 唯一写入者、跨 owner 写一律禁止」在文件粒度上因此有了**第二个**反例
（第一个是 `channels/`，已由 [#23](https://github.com/jiangxidong/EduApplication/issues/23) 承接）。
两个反例合起来把 #23 的题面从「`channels/` 的例外」变成「唯一写入者必须按节/阶段定义，不能按文件」。
