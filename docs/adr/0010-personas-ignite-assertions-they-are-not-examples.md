# 样例档案是断言点火器，不是示例

验收标准要三个虚拟申请人档案做 dry-run 回归。[#14](https://github.com/jiangxidong/EduApplication/issues/14) 的题面里问了一句别的票都没问过的话：这三个档案**如何同时成为可发布的资产，而不是死文件**。

竞品在这件事上留下的是**两个方向相反**的失败，而且它们出自同两个 repo：

**死资产。** `academic-program-application` 的 5 个 genre guide 共 195 行、整个 `examples/` 254 行，在 `SKILL.md` 中**零引用**（`docs/research/competitor-skills.md:46`）。写了，没有任何东西会去读它。

**形状污染。** `taught-master-applications-skill` 的 `cv-preview-stem.md` 自称匿名模板，却列着 MyBatis 与具体爬虫项目，而 `SKILL.md` **指示把它当作 preview shape 使用**（同文件 `:48`）。这里有两段独立的伤害：泄露（它是某个真人的），以及**污染**（那个形状会串进每一个真实用户的简历）。[#17](https://github.com/jiangxidong/EduApplication/issues/17) 的单向阀已经处理了泄露——样例档案必须正向生成、不得反向脱敏。**污染这一段还没有对策。**

于是「让 `SKILL.md` 引用它，它就不是死资产了」这个最自然的补救，**恰好踩中第二个坑**。而且我们会踩得比竞品更重：竞品那份至少是真人写的简历，形状还算自然；本产品的样例档案是**按断言覆盖设计出来的**，形状故意是怪的——一个人同时跨专业、缺件、有敏感素材、只能做 support pack。这种形状串进真实用户的产物里，后果比一份陌生人的简历坏得多。

决定：**样例档案的存在理由是点亮断言，不是示范形状。** 两条推论各管一头：

**归属判据。** 一个维度能进样例档案的轴集，当且仅当——**把它去掉，就有一条已承诺的断言永远不会被触发**。这条判据与 [ADR 0005](0005-basis-points-at-an-existing-checked-fact.md) 给 `tier_basis` 定的准入测试同构：都是拿「它挂在哪条已存在的东西上」代替「它像不像那么回事」。用它筛 #14 票面原列的八个候选，**预算**、**申请学校数量**、**目标项目类型**当场出局——它们让样例档案更像真人，但一条断言都不 gate。

**流向红线。** **任何 `SKILL.md` 都不得引用 `evals/`。** 样例档案的「活」不来自被 `SKILL.md` 引用，来自**回归套件每次跑它**；引用关系的方向是「测试 → 产物」，不是「产物 → 示例」。README 可以链过去——那是给人读的，不是给 agent 读的。

这与 [#9](https://github.com/jiangxidong/EduApplication/issues/9) 那条「任何 `SKILL.md` 不许出现全景流程图」是同一台机器：**agent 会照着它读到的东西产出**，所以内容进不进 `SKILL.md` 的判据不是「有没有用」，而是**照抄它会不会出事**。

## Consequences

**这是产品的第二条单向阀。** 第一条是仓库 → 工作区可流、反向绝不（#17）。第二条是 `evals/` → `SKILL.md` 禁流。两条方向不同但成因相同：**跨越那道边界的内容会被当成范本复制**，而复制的代价一次比一次难收回。

**「像不像真人」不再是判据，代价要明写。** 三个样例档案各自内部自洽，但组合是设计出来的。这直接接住了竞品的第三个坑——`academic-program-application` 的 7 个 example 全是「现代中国基督教史」，`application-essay-skill` 全是环境/设计/政策（`competitor-skills.md:51`）：**example 一旦被当成「真人长什么样」，它要么泛化性不足，要么开始骗人。** 把它定性为点火器，这两个死法一次关掉。

**发布是安全的，因此应当发布。** 样例档案进仓库、README 可链，别人能复现验收；而红线保证它们不会被 agent 当范本读走。若改为不发布（`evals/` 进 `.gitignore`），MIT 开源发布的意义会打折——别人无法验证「3 档 dry-run 回归」这句验收标准。

**反向代价高。** 一旦某个 `SKILL.md` 开始引用样例档案，被它塑形的用户产物已经产生，收回引用不能收回那些产物。这条红线便宜的时候是现在——`SKILL.md` 还没写。

**它不保证样例档案有用。** 红线只挡住一种死法（污染），另一种（死资产）靠的是回归套件真的在跑。**若回归套件停跑，样例档案立刻退化成竞品那 254 行。** 这是本决定唯一的软肋，且没有结构性对策——只能由「验收标准包含它」这件事顶着。
