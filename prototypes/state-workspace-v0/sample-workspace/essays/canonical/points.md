# Canonical 要点（虚构）

> **存在的理由**：UIUC 要的不是一篇文章，是四段互相独立的回答。
> 从长文自动截会得到四段互相重复、且都缺开头结尾的碎片。

每条要点 = 一个可独立成段的完整论点 + 它的素材来源。

| # | 论点 | 素材 | 可回答哪类题 |
|---|---|---|---|
| P1 | 我的工程经验暴露了系统性训练的缺口 | `materials/01` | 为什么读这个学位 |
| P2 | 我有把陌生环境拆成可执行步骤的具体方法 | `materials/02` | 个人背景 / 逆境 |
| P3 | （待补 —— 素材不足 3 个） | — | 多样性 / 贡献 |
| P4 | （待补） | — | 职业目标 |

P3 / P4 留空是**素材门槛未达标的正常体现**，不是文件缺失。达标与否跑 `../../derive-demo.sh` 现算。
