# Canonical 要点（虚构）

> **存在的理由**：UIUC 要的不是一篇文章，是四段互相独立的回答。
> 从长文自动截会得到四段互相重复、且都缺开头结尾的碎片。

**一个 `###` = 一类短答题**，节内是可独立成段的完整回答。
节标题（题类）是**自由文本，不是封闭词表**——写它的人是在判「这一段适合答哪类题」，不是在填枚举。

用到哪几条主张只记在 frontmatter 的 `claims:`，**正文不再列一遍**
（[#32](https://github.com/jiangxidong/EduApplication/issues/32)：分配能算出集合、集合算不出分配，两处存必有一处是投影）。
**空节 = 这类题还没有能写的东西**，那就是缺口本身；同全工作区「不预建空目录、缺席本身是信息」一脉。
🔴 空节里**不写「待补」「素材不足 N 条」这类当前状态**（`CONTRACT.md` §1.5）——
哪几节空着、缺的是什么，跑 `../../../derive-demo.sh` 现算。
