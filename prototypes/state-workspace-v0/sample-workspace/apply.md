# 申请工作区

> ⚠️ **本目录是原型样例。申请人「林小雨」及其全部经历、项目、成绩为完全虚构。**
> 三所目标项目是真实存在的，其**申请约束取自 2026-08 的官网调研**，仅供演示文件契约，**不得当作现行事实使用**。

## 这是什么

本目录是你这一季申请的**唯一状态源**。所有会话都从这里读、往这里写。
换一台电脑、换一次会话、隔三个月回来——只要这个目录还在，进度就续得上。

## 目录对照

| 目录 | 是什么 | 你会手改吗 |
|---|---|---|
| `profile.md` | 你的基本信息与学历经历 | 会 |
| `programs.md` | 项目池：你在考虑的所有项目 | 会（也可以让 agent 改） |
| `claims.md` | 主张集：你希望招生官相信的、关于你自己的断言 | 会 |
| `channels/` | 每所学校的申请要求（字数、格式、截止、推荐信机制） | 一般不用 |
| `materials/` | 文书素材库：可跨项目跨版本复用的真实经历 | 会 |
| `essays/` | 文书 canonical（三个形态）与历史版本 | 会 |
| `documents/` | 成绩单、学位证等原件扫描 | 会（放文件进去） |
| `recommenders.md` | 推荐人与各校推荐信状态 | 会 |
| `packets/` | 各校的网申准备包（**自动生成，删了能重建**） | 不用 |
| `log.md` | 每次会话做了什么、下一步是什么 | 不用 |

## 申请季与换季

当前申请季：**2027fall**

改这里的 `season` **不会触发全表降级** —— 降级是**惰性**的：各阶段下次进入时，按
`programs.md` 与 `channels/*.md` frontmatter 里那张 `season_downgraded` 表**比对自己那一行**，
落后于本季才就地降级**自己那几节**，把 `✓ <链接>` 换成 `待核实（2026fall 核过：<链接>）`，
并把自己那一行重戳成本季。deadline、学费、门槛每年都变，上一季核过的比没核过的更危险；
但一口气替所有阶段降级是**跨 owner 的写**，没有任何一个阶段有这个权限。
未被访问的节保持上季标记 —— 比假装重查过更诚实。

🔴 **本文件的 `season` 是全工作区唯一的参照点，不删。** 被删掉的是那些文件**自己的** `season` 字段：
它会被第一个进来的阶段刷成本季，其余阶段就永远比对不出落后、永远降不了级。
形态与辖区见 `../CONTRACT.md` §4。
