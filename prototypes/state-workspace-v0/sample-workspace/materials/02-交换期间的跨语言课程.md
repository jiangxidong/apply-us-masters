# 素材 02 · 交换期间的跨语言课程（虚构）

**一句话**：2023 春在台湾交换，第一次用非母语上专业课，前六周听不懂。

**具体**：
- 时间：2023-02 ~ 2023-06，4 门课
- 我做的：把每节课录音转文字，课后逐句对照讲义；第七周起改成课前预读原文教材
- 结果：期末 4 门 B+ ~ A-；其中「计算机网络」是当学期最高分之一
- 谁能证实（**不属于三问判据**，是独立属性，供推荐人选人用）：交换期间的授课教师李老师（推荐人候选 R3，联系方式不在手）；本科毕设导师王教授（R1）能证实同期的学术表现

**支撑的论点**：适应陌生学术环境的具体方法，不是「我很努力」。

**原始出处**：用户口述（首轮 intake 问「有没有一次环境突变」时讲出来的，简历上没有）。

**⚠️ 风险**：这类「克服困难」素材极易滑进 generic。定稿前必须核验是否只剩下情绪没有动作。
