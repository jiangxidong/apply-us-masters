# 状态层文件契约（故意写坏的夹具：split-is-declared）

`split-is-declared` 必须对本文件翻红，否则它是恒真的（ADR 0017 推论 2）。
违规点：`materials/*.md` 与 `essays/canonical/*.md` 两行 owner 列都写成多写入者（含
「按行」「按列」标记），但两条路径都不在 ADR 0008 限定 1 已声明的三种切法
（`channels/` 十节封闭词表 / `claims.md` 的行 / `programs.md` 的 13 列）之内——
「一个单元两个写入者」必须来自契约里预先声明、脚本能枚举的结构，不许临时发明切法。

## 1.1 三个文件（极小形状，仅供本夹具测试）

`CONTRACT.md` §1.1 逐字同此。第 2、3 行是本夹具专门捏造的两处违规。
