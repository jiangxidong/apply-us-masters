# 词汇表（故意写坏的夹具：citation-is-partial）

`citation-is-partial` 必须对本文件翻红，否则它是恒真的（ADR 0017 推论 2）。
违规点：「派生视图」词条正文里直接举出了 `CONTRACT.md` §1.5 名单的具体项名——引用配额判据
（ADR 0011「引用配额」＋ #42 补节⑤）要求「花在读判别式时会判错的边界例上，不花在『有哪些项』
上」，正例零项才是正确形态；举名字即等于把词汇表变成第二个权威。

**派生视图** — `—`
从真相源现算现打、绝不落盘的东西，如待核实清单、缺口清单、选校清单等，具体有哪些参见
状态层契约 §1.5 的完整名单。

**缺口** — `—`
一处应有而实无的空位（本词条只为界定上面「派生视图」正文的终点而存在，不是真实定义）。
